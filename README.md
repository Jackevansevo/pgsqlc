# pgsqlc

Generate typed, async Python functions from sqlc-style SQL query files, for
Postgres and asyncpg.

## Usage

pgsqlc reads types from a live database, so the schema must already be loaded
into it. It doesn't apply schema files itself: load them with `psql`, then
point pgsqlc at the database. Everything pgsqlc does runs in a transaction
that is rolled back, so it never changes the database.

Create an empty database:

```bash
createdb exampledb
```

Load your schema into it:

```bash
psql exampledb -f schema.sql
```

Generate the code:

```bash
pgsqlc queries/ -o src/app/db --db postgresql://localhost/exampledb
```

| Flag | Meaning |
|---|---|
| `QUERIES...` | `.sql` files or directories (`*.sql`, one level deep). One module per file. |
| `-o/--out` | Output package directory. |
| `--db` | Postgres 16+ URL (default `$DATABASE_URL`). |
| `--check` | Write nothing; exit 1 if any generated file would change. |

## Example

Given this schema:

```sql
create table authors (
    id bigserial primary key,
    name text not null,
    bio text
);
```

and this query file, `queries/authors.sql`:

```sql
-- name: GetAuthor :one
-- Becomes the docstring.
select * from authors where id = @id;

-- name: CreateAuthor :single
insert into authors (name, bio) values (sqlc.arg(name), sqlc.narg(bio)) returning *;

-- name: DeleteAuthor :exec
delete from authors where id = $1;
```

pgsqlc generates `models.py`:

```python
"""Code generated by pgsqlc. DO NOT EDIT.

Shared enums, composite types and table models.
"""

from dataclasses import dataclass
from typing import Self

from asyncpg import Connection, Pool, Record
from asyncpg.pool import PoolConnectionProxy

type DB = Connection | Pool | PoolConnectionProxy


class NoRowsError(LookupError):
    """Raised when a :single query returns no rows."""


@dataclass(frozen=True, slots=True, kw_only=True)
class Authors:
    id: int
    name: str
    bio: str | None

    @classmethod
    def from_record(cls, r: Record) -> Self:
        return cls(id=r[0], name=r[1], bio=r[2])
```

and `authors.py`:

```python
"""Code generated by pgsqlc. DO NOT EDIT.

Source: authors.sql
"""

from typing import Final

from .models import DB, Authors, NoRowsError

GET_AUTHOR: Final = "select * from authors where id = $1"


async def get_author(db: DB, *, id: int) -> Authors | None:
    """Becomes the docstring."""
    row = await db.fetchrow(GET_AUTHOR, id)
    return None if row is None else Authors.from_record(row)


CREATE_AUTHOR: Final = "insert into authors (name, bio) values ($1, $2) returning *"


async def create_author(db: DB, *, name: str, bio: str | None) -> Authors:
    row = await db.fetchrow(CREATE_AUTHOR, name, bio)
    if row is None:
        raise NoRowsError("query CreateAuthor returned no rows")
    return Authors.from_record(row)


DELETE_AUTHOR: Final = "delete from authors where id = $1"


async def delete_author(db: DB, *, p1: int) -> None:
    await db.execute(DELETE_AUTHOR, p1)
```
